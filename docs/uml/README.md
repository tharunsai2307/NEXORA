# Unified Modeling Language (UML) Specifications

This directory contains architectural and design models for the Smart Building Digital Twin project across the 7 milestones:

- **Class Diagrams**: Domain entities (Building, Floor, Room, Sensor, Telemetry, Alert, User, Role).
- **Sequence Diagrams**: Sensor telemetry streaming, AI inference pipeline, emergency evacuation dispatch.
- **State Machine Diagrams**: Sensor lifecycle, emergency building state transitions.
- **Component & Deployment Diagrams**: Microservice container distribution and Docker networking.
